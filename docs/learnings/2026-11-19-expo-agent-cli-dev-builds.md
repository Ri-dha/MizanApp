# 2026-11-19 — Running the Expo app locally

- Run Expo commands through `npx --yes @expo/agent-cli@latest` (the Expo skills' rule). One project
  has one dev server: start iOS with `dev --ios --local --dev-client --device "iPhone 17" --detach`;
  for Android, `dev:stop` first, then `dev --android ... --device emulator-5554`, which builds,
  installs and serves both platforms.
- The agent CLI needs `adb` on PATH for Android checks (`smoke`, `runtime:*`):
  `export ANDROID_HOME=$HOME/Library/Android/sdk PATH=$ANDROID_HOME/platform-tools:$PATH`, and
  Gradle uses Android Studio's JDK (`JAVA_HOME=~/Applications/Android Studio.app/Contents/jbr/Contents/Home`).
- `smoke --ios|--android` proves the app boots; `runtime:tap run-vectors` and
  `runtime:tree --all` drive and read the diagnostics screen without touching the simulator.
- SQLCipher only works in a development build; `PRAGMA cipher_version` answers only when it is
  compiled in. The raw key is set with `PRAGMA key = "x'<64 hex>'"`.
- `expo-env.d.ts` is generated by the first `expo start`; before it exists, `tsc` reports the
  template's CSS imports as missing modules.
